# PrimeiraChamada

Protótipo responsivo em React e Vite a partir das versões mobile e desktop das sete telas e estados exportados do Figma. A partir de 900 px, a navegação passa para o cabeçalho e as páginas usam os layouts em colunas das referências de desktop.

```bash
npm ci
npm run dev
```

Para gerar e conferir a versão de produção, rode `npm run build` e `npm run preview`.

Para abrir no celular pela mesma rede Wi-Fi, rode `npm run dev -- --host` e acesse o endereço **Network** exibido pelo Vite.

Os dados de demonstração são locais. Progresso, votos, mensagens e relatos ficam no armazenamento do navegador. Anexos são representados por metadados. O player reproduz o estado visual do Figma e direciona para a transcrição, pois os arquivos de vídeo não foram fornecidos. Os botões de download oferecem resumos de texto gerados localmente e informam o tamanho real antes de salvar. Números e operações e Porcentagens têm páginas de resumo para que os atalhos do protótipo tenham um destino.
